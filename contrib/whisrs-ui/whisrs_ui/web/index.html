    Vocabulário

    Os termos vão para o MAI como lista de frases e para o Luna no fim do prompt, para saírem escritos como estão aqui.

    Substituições fixas

    Trocadas no texto sempre, antes do Luna. Servem para o que o modelo erra sempre do mesmo jeito.

    Ouvido comoEscreverRemover

    Prompt do Luna

    A instrução que o LLM recebe com cada transcrição. O vocabulário é anexado ao fim dela.

    O que vai para o Luna

    A mensagem de sistema como o whisrs a monta. O texto transcrito vai em seguida, como mensagem do usuário.
